Projet App Inventor — Secteurs & Métiers (4e)

Objectif : créer une application mobile avec 1 écran logo → liste de métiers → fiche métier.
Chaque élève choisit un secteur, puis complète les informations sur les métiers.
Durée conseillée : 2 à 4 séances
Production finale : .AIA + captures + mini oral
Étapes guidées
Progression enregistrée ✅
0%
0
Choisir ton secteur + préparer tes métiers
Tu choisis un secteur (menu) et tu te prépares à écrire les infos.
⬜
Quand tu choisis un secteur, la liste des métiers se remplira automatiquement à l’étape 3.
Recommandation : 3 à 6 métiers.
À préparer (avant de coder) : pour chaque métier → 3 à 5 lignes : rôle, compétences, outils, études, où on travaille, etc.
1
Créer le projet App Inventor + préparer les écrans
Projet + 3 écrans : Accueil → Métiers → Infos métier
⬜
À faire dans App Inventor :
1) New Project → nom : SecteursMetiers_TonPrenom
2) Crée 3 écrans : Screen1 (Accueil), ScreenJobs, ScreenInfo
Plan de l’app
Screen1 (logo + bouton) → ScreenJobs (liste) → ScreenInfo (texte + retour)
2
Design Screen1 (logo + bouton)
Un logo/une image + un bouton “Voir les métiers”.
⬜
Composants à ajouter :
- Image (logo du secteur)
- Label (titre du secteur)
- Button (aller vers la liste)
Conseil : centre tes éléments (AlignHorizontal/Vertical).
Tu peux aussi écrire “Découvrir les métiers”.
3
Créer la liste des métiers (ScreenJobs)
Une ListView : cliquer sur un métier ouvre sa fiche.
⬜
Composants sur ScreenJobs :
- Label (titre : “Métiers du secteur …”)
- ListView (liste des métiers)
- Button (retour à l’accueil)
Tu peux modifier la liste : ajoute/retire des métiers si nécessaire.
Aperçu de ta liste
Choisis un secteur pour voir les métiers.
4
Écran fiche métier (ScreenInfo)
Afficher le métier choisi + ses informations.
⬜
Composants sur ScreenInfo :
- Label (nom du métier)
- Label ou TextBox (infos du métier)
- Button (retour à la liste)
5
Blocks : navigation + affichage (le cœur du projet)
Bouton → ScreenJobs ; clic métier → ScreenInfo + texte.
⬜
Idée simple (niveau 4e) :
- Screen1 ouvre ScreenJobs
- ScreenJobs envoie le nom du métier à ScreenInfo (Start Value)
- ScreenInfo affiche le texte correspondant au métier
Pseudo-blocs
1) Screen1.ButtonClick → open ScreenJobs
2) ScreenJobs.ListView.AfterPicking → open ScreenInfo with start value = ListView.Selection
3) ScreenInfo.Initialize → selectedJob = get start value → if selectedJob = “…” then set InfoText = “…”
6
Tests + amélioration + finition
Tester, corriger, rendre l’app claire et jolie.
⬜
Tests indispensables :
- Le bouton fonctionne (Accueil → Liste)
- Chaque métier ouvre la bonne fiche
- Les boutons retour fonctionnent
- Texte lisible (taille, retours à la ligne)
7
Production finale : ce que tu dois rendre
Export + preuves + mini présentation
⬜
À rendre :
1) Le fichier projet .aia
2) 2 captures d’écran : Accueil + Fiche métier
3) Mini oral (30 s) : secteur + 3 métiers + pourquoi
La progression est enregistrée sur cet ordinateur.
